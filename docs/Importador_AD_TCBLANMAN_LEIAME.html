Importador de Dados

Introdução

Este documento tem por finalidade orientar quanto às regras e forma de preenchimento das colunas dos templates disponíveis para serem baixados e importados no Importador de Dados.

Padrão Importador

Os templates disponíveis estão categorizados por dois padrões de importação: Os que seguem do importador e os que não seguem. Esta indicação está disponível na coluna "Padrão" da aba "Baixar Templates" do Importador de Dados.

Desta forma, os templates que possuírem a informação "Sim", nesta coluna, seguem o padrão do importador; já os templates que possuírem a informação "Não", não utilizam do padrão. Esta indicação deve ser observada, e seguida, para o correto preenchimento dos templates, e para o bom comportamento da importação de dados em si.

A seguir estão as diferenças entre os dois tipos de padrão.

Templates que seguem o padrão do importador

Os templates que seguem o padrão possuem tratativas específicas que possibilitam, ao usuário, escolher entre importar templates contendo apenas as colunas essenciais, ou todas as colunas de um determinado cadastro ou movimentação.

Além desta, existem tratativas específicas para otimizar o preenchimento dos templates e a importação em si, no que tange o relacionamento de dados através das colunas iniciadas com o prefixo "ID_EXTERNO_+[nome da coluna]".

Templates que NÃO seguem o padrão do importador

Os templates que NÃO seguem o padrão, não possuem as tratativas específicas mencionadas para os templates que seguem o padrão.

Estes templates possuem apenas o ".csv" contendo todas as colunas presentes na respectiva tabela. Além disso, as tratativas para relacionamento de dados, que são as colunas iniciadas com o prefixo "ID_EXTERNO_+[nome da coluna]", não estão disponíveis para templates que não possuem o padrão do importador.

Acesse o manual do Importador de Dados clicando aqui para consultar mais detalhes.

Relacionamento entre tabelas

Caso o arquivo ".csv" possua colunas que fazem referência a dados de outras tabelas, estes dados relacionados devem ser verificados e corretamente preenchidos no arquivo para evitar erros na importação ou problemas no relacionamento de dados.

Para relacionar dados utilizando o código do Sankhya Om, é necessário que as colunas que requerem este código sejam preenchidas com o valor correspondente ao registro em questão.

Coluna "AD_IDEXTERNO"

Para que seja possível realizar a atualização de registros, será necessário criar a coluna "AD_IDEXTERNO" no dicionário de dados do Sankhya Om, bem como o seu índice no banco de dados.

Esta coluna será utilizada como chave para verificar se um registro que será importado para uma determinada tabela já existe na base. Os registros já existentes serão atualizados de acordo com os dados informados no template ".csv", caso a opção "Atualizar os registros" tenha sido selecionada para a pergunta "Deseja atualizar os registros existentes?" na aba "Importar Dados" do Importador de Dados.

Caso a opção "Não atualizar" tenha sido selecionada, os registros que possuírem o valor da coluna "AD_IDEXTERNO", coincidente com algum valor na coluna de mesmo nome no ".csv", serão ignorados na importação e os dados já existentes na base serão mantidos.

Arquivo Leia-me

O arquivo leia-me fornece uma descrição completa de cada uma das colunas a serem preenchidas no arquivo ".csv" da tabela. No caso dos templates de entidade as informações abrangem cada um dos arquivos que a compõem. Essa descrição inclui:

Coluna: Representa o nome da coluna na tabela.
Tipo: Representa o tipo de dado que deve ser preenchido na coluna.
Tamanho: Representa o limite máximo de caracteres que é permitido na coluna.
Descrição: Apresenta uma breve descrição da coluna.
Essencial: Se marcada com um "X", o preenchimento da coluna no ".csv" é essencial.
Valor default: Informa se existe um valor default para a coluna caso não seja informado nenhum dado. Para as colunas que não possuem um valor padrão a linha da coluna estará vazia.
Valores permitidos / Descrição: Quando existe uma lista de valores permitidos, o campo só poderá receber um dos valores listados. Esta coluna apresenta os valores seguidos de suas respectivas descrições (separados por "->"). Exemplo: N -> Não. Apenas o valor deve ser preenchido no template ".csv".
